Currently, this site has no content, although that will change soon.

The domain was registered with Cloudflare (as they provide at-cost domain registration) who still provide the authoritative DNS. The mail service is provided by iCloud's custom email domain service as it's a good-value option (for those with an existing iCloud+ subscription) and even actually works! This page (yes, the one you're looking at right now) is hosted in an S3 bucket with a Cloudfront layer infront. Cloudfront is mostly useful here for so that HTTPS is supported, the edge caching is a bonus. All of the AWS configuration lives in a Cloudformation YAML file so that I can easily change it once Thoughtful Tutors scales to a ga-trillion users.
