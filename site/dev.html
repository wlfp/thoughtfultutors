Thoughtful Tutors developer information

The domain was registered with Cloudflare (as they provide at-cost domain registration) who also provide the authoritative DNS. The mail service is provided by iCloud’s custom email domain service as it’s a good-value option (for those with an existing iCloud+ subscription) and even actually works! This page (yes, the one you’re looking at right now) is served by Cloudflare Workers static assets, so domain, DNS, HTTPS and hosting all live in one place. The whole site is three hand-written HTML files with their styles inline and no web fonts to download, which keeps it small enough that minifying it would save almost nothing.
